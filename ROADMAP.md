# Mona's Bookmark Manager Roadmap

Plan and track improvements that make saving and organizing bookmarks fast, reliable, and easy to recover.

| Area | Item | Type | Priority |
| --- | --- | --- | --- |
| Discovery | Search and filter bookmarks | 🚀 | high |
| Bookmark management | Edit a bookmark | 🚀 | high |
| Organization | Tags or folders | 🚀 | medium |
| Data portability | Import and export bookmarks | 🚀 | medium |
| Data integrity | Duplicate slugs on re-add | 🐞 | medium |
| Validation | Empty-URL submissions | 🐞 | high |
| Persistence | Bookmarks lost when localStorage is cleared | 🐞 | medium |

## 🚀 Planned features

- 🔎 Search and filter bookmarks — priority: high
- ✏️ Edit a bookmark — priority: high
- 🗂️ Organize bookmarks with tags or folders — priority: medium
- 📦 Import and export bookmarks — priority: medium

## 🐞 Known bugs & risks

- 🐞 Duplicate slugs on re-add — priority: medium
- 🐞 Empty-URL submissions may pass validation — priority: high
- 🐞 Clearing localStorage can permanently remove bookmarks — priority: medium
